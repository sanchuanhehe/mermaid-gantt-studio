# Mermaid 本地排期编辑器

左侧修改 Mermaid，右侧自动预览。内置当前 WS53 计划和清晰的泳道分隔样式；可以导出源码、SVG 和 PNG。

## 启动

需要 Node.js 18 或更高版本，无需安装 npm 依赖。

- macOS：双击 `启动编辑器.command`。
- 其他系统：在此目录执行 `npm start`。
- 地址： http://127.0.0.1:4173 。关闭终端或按 Ctrl+C 停止服务。
- 端口被占用时可执行 `PORT=4174 node server.mjs`（Windows PowerShell 使用 `$env:PORT=4174; node server.mjs`）。

请通过本地服务打开，不要直接双击 index.html：模块和示例文件需要 HTTP。

## 使用

1. 修改左侧源码，停止输入约半秒后自动更新；⌘/Ctrl+Enter 立即刷新。
2. 左边设置画布宽度、比例、字号和行高。默认 2560px、自动高度；16:9 需要足够容纳全部任务，否则显示最低高度提示。
3. 预览区可适应宽度或放大查看。放大预览不影响导出尺寸。
4. 导出 SVG 为矢量图；PNG 默认 1×，可在「备注与导出」中切换倍率。
5. 「打开 .mmd」导入源码时会清空示例的发布日期线与备注，可重新设置。
6. 输入错误时保留上一次成功的图片，停止导出，避免误下载旧图。修改正确后恢复。

## 渲染范围

- 内置官方 Mermaid 11.17.2，无需 CDN；所有编辑和导出都在浏览器本机完成，无上传接口。
- 甘特图复用 CLI v2 的 browser-render.mjs：官方排期、原生几何、增强泳道分隔、右侧标签、风险颜色与红色发布日期线。
- `after`、`until`、`excludes`、`includes`、`compact` 等语法由官方引擎处理，源内配置依官方 Mermaid 优先级生效。
- 非甘特图自动使用官方样式。泳道、任务日期、备注与发布日期线只应用于甘特图。
- 日期以当前浏览器时区处理；「显示今天」使用本机日期。
- SVG/PNG 是静态图片，不执行 Mermaid click 回调。原生图中使用 HTML/外部图片时，浏览器可能限制 PNG 导出；可使用 SVG。
- 单张 PNG 上限 3200 万像素、单边 16384px，避免浏览器画布内存过大。
- 本地网页不保存草稿，离开前请「保存源码」。源码保存不包括侧栏样式设置。
- 可选 WebMCP 接口在支持的浏览器注册；普通浏览器不受影响。

`dist/vendor/mermaid.js` 为官方固定版本浏览器包，许可证见同目录 MERMAID-LICENSE。网页部署未启用；server.mjs 仅监听 127.0.0.1。

## 在预览中直接编辑任务

点击甘特图中的任务条或名称，修改名称、开始时间 / 依赖、结束时间 / 工期、完成 / 进行中 / 风险 / 里程碑状态，点击「应用到源码」。源码立即更新并重新预览。可以用「撤销图上修改」撤销最近一次可视化修改；如果之后手动改过源码，不会覆盖新的修改。

这项功能适用于带唯一显式 ID 的任务（内置 40 个任务全部具备 ID）。只改对应任务行，保留其他行、任务 ID 与未修改的依赖排期；排期有效性仍由官方引擎检查。没有明确 ID、重复 ID、无法唯一映射的任务以及非甘特图暂不支持点击编辑。尚不支持拖动时间条和跨泳道拖动。

更新网页前先保存当前源码，再刷新本地页面载入新功能。

## 手势与滚轮缩放

在预览区使用触控板捏合，或按住 Ctrl / ⌘ 滚动滚轮，以指针位置为中心缩放。勾选预览底部「滚轮直接缩放」后，无需按键。缩放范围 5%–400%，菜单显示当前比例；选择「适应宽度」即可复位。缩放只影响预览，不改变源码或导出像素。

## 工作台布局

顶部切换「源码与预览」「专注预览」「专注源码」。画布尺寸、样式、日期、备注与导出倍率统一放在右上角「画布设置」。预览工具栏可直接点击 ＋ / − 缩放，菜单可恢复适应宽度。窄屏自动上下排列编辑与预览区。


## 图形化编辑

预览更新后，点击标题、泳道名称、任务、备注或图例打开编辑表单。没有标题或备注时，可以通过预览工具栏的「标题」「备注」添加。点击「＋ 泳道」创建泳道和首个节点，点击「＋ 节点」选择已有泳道并填写排期；任务 ID 自动生成。日期与依赖仍由官方 Mermaid 解析，日期格式须与源码的 dateFormat 一致。可用「撤销图上修改」撤销最近一次图形化修改。

标题、泳道和节点写回标准 Mermaid 语法。备注与图例使用单行 `%% gantt-studio {…}` JSON 注释保存，重新导入本编辑器可恢复；其他 Mermaid 工具会忽略这些扩展注释，CLI 暂不读取它们。修改图例只改变文字，不改变状态颜色。其他图表类型保持官方预览，不提供上述甘特图编辑功能。
